# Golos Text

Шрифт презентации управленческой отчётности (сборка PDF, `service/mrpresentation`).

Файлы — статические начертания (400, 500, 600, 700, 800), полученные из вариативного шрифта
`GolosText[wght].ttf` (Google Fonts, https://github.com/google/fonts/tree/main/ofl/golostext)
утилитой `fonttools varLib.instancer`. Лицензия — SIL Open Font License 1.1.
